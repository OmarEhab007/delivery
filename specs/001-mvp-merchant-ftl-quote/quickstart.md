# Quickstart: MVP Merchant FTL Quote Flow

## Backend

1. Copy environment template and set required values.
2. Start API server.

```bash
npm install
npm run dev
```

## Frontend (Merchant Portal)

1. Install client dependencies.
2. Start the dev server.

```bash
cd client
npm install
npm start
```

## Sanity Checks

- Create a merchant shipment request.
- Submit and accept a quote.
- Assign broker and upload compliance docs.
- Verify tracking update display.
